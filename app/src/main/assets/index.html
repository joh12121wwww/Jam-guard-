PREFERENCES & INTEGRATION

Make it yours.

Device & operating mode

Monitoring continues with a foreground notification after you leave the app. Android force-stop, reboot or battery restrictions can end it; reopen the app to resume. This mode does not detect vehicle ignition.

Telegram gateway

Private chat: start the bot first. Group: add the bot and grant permission to send. Bot tokens are sensitive: enter yours here, never commit it to GitHub. Disabling Telegram pauses pending deliveries.

Detector sensitivity

These change the detector only after it acknowledges and returns saved values.

Detector Wi-Fi & Telegram

Optional direct gateway for compatible firmware. A phone gateway is sufficient; enable one alert path at a time to avoid duplicate notifications.
